Tidbits: 
repository network contains all commit by data
master branch saves your main progress
syncing local (.git) and remote (github) repository is possible

===============================================
Create repository:
$ git init
$ git add README.md
$ git commit -m "first commit"
$ git remote add origin [repository_address]
$ git push -u origin master

Explaination:
# git initialization
# adding a readme.md file optional
# commiting to git all files in dir, for staging area use git add before commit
# adding commited files to a remote repository, origin name of remote changeable but not recommended
# pushes local to remote, syntax: git push [linker] [name of remote] [name of branch]

Push Existing git repository: i.e. local to remote
$ git remote add origin [repository_address]
$ git push -u origin master

Git Ignore:
files starting with .file.type are hidden files
used for handling sensitive and not useful hidden files
get a gitIgnore template from github/gitignore repository

Procedure:
     write name of files to ignore i.e $secrets.txt
     ignore all files of specific type: $*.type
     # for comment

==============================================
BRANCHING:
sort of like an off-track experimental branch derived from a version of the master branch
MERGE to add it to master.
used for testing and reviewing the project before adding it to the master branch

$ git branch                                  # all branches
$ git branch [branch_name]         # make branch string

MERGE: #in master branch
merge doen't delete the branch
in a branch request, branch takes precedence over master i.e. branch changes are implemented

$ git merge [branch_name]
