Bash is a CLI 

Popular Commands:
     ls: list
     cd: change directory     
          cd ..               : previous directory
          cd 'directory'  : 

     pwd : print working directory
     *      : all

     dir : directory
          mkdir : make directory 
          touch : touch file.type for making file
          open  : open file.type
          rm      : rm file.type for remove file
               rm -r : remove directory
               rm -rf :remove by force

GIT as version control:
// $ represents command start

     create local git repository : 
     $git init
     
     #red is not yet in staging area
     see what is in your staging area and their status: 
     $git status

     add a file to staging area: 
     $git add file.type
          add all files in dir: 
          $git add .
          remove from staged: 
          $git rm --cached -r

     commit under version control: $git commit -m "string: be precise, in present tense"
     commit log: $git log 

     DELETE git branch
     $ git branch --delete [branch_name]
          for remote branch
          $ git branch --delete --remote origin/[branch_name]

     DELETE git repository without deleting local files:
     $git rm --cached -r [directory_to_remove]

     check differences b/w current file and last commit: 
     $git diff

     rollback to previous version: 
     $git checkout file.type

          for all: 
          $git checkout -- . 
          $git checkout . 

          specific commit: 
          $git checkout [commit_id] file.type

          can also use SWITCH to switch between branches
          $ git switch [branch_name]

     REBASING:
          way of integrating one branch into another, different from merge
          changing the base of your branch from one commit to another making it appear as if you'd 
          created your branch from a different commit
          $ git --rebase      # confirm
          $ git rebase --quit

     FIXING UPSTREAM:
     used whem remote upstream is gone; where you push files
     $ git branch --unset-upstream
