GIT as version control:
// $ represents command start

     create local git repository : 
     $git init
     
     #red is not yet in staging area
     see what is in your staging area and their status: 
     $git status

     add a file to staging area: 
     $git add file.type
          add all files in dir: 
          $git add .
          remove from staged: 
          $git rm --cached git

     commit under version control: $git commit -m "string: be precise, in present tense"
     commit log: $git log 

================================================
     DELETE git branch
     $ git branch --delete [branch_name]
          for remote branch
          $ git branch --delete --remote origin/[branch_name]

     DELETE git repository without deleting local files:
     $git rm --cached -r [directory_to_remove]

     check differences b/w current file and last commit: 
     $git diff

================================================
     ROLLBACK to previous version: 
     $git checkout file.type

          for all: 
          $git checkout -- . 
          $git checkout . 

          specific commit: 
          $git checkout [commit_id] file.type

          can also use SWITCH to switch between branches
          $ git switch [branch_name]

REBASING:
     way of integrating one branch into another, different from merge
     changing the base of your branch from one commit to another making it appear as if you'd 
     created your branch from a different commit
     $ git --rebase      # confirm
     $ git rebase --quit

Create repository:
$ git init
$ git add README.md
$ git commit -m "first commit"
$ git remote add origin [repository_address]
$ git push -u origin master

Explaination:
# git initialization
# adding a readme.md file optional
# commiting to git all files in dir, for staging area use git add before commit
# adding commited files to a remote repository, origin name of remote changeable but not recommended
# pushes local to remote, syntax: git push [linker] [name of remote] [name of branch]

Push Existing git repository: i.e. local to remote
$ git remote add origin [repository_address]
$ git push -u origin master

Git Ignore:
files starting with .file.type are hidden files
used for handling sensitive and not useful hidden files
get a gitIgnore template from github/gitignore repository

Procedure:
     write name of files to ignore i.e $secrets.txt
     ignore all files of specific type: $*.type
     # for comment

BRANCHING:
sort of like an off-track experimental branch derived from a version of the master branch
MERGE to add it to master.

MERGE: #in master branch
merge doen't delete the branch
in a branch request, branch takes precedence over master i.e. branch changes are implemented

$ git merge [branch_name]
